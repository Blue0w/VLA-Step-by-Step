# 第 02 章实验 · 逐项控制机械臂

## 预期效果

沿用第 01 章的红杯场景，手动给机械臂发送几条动作。每组只改变一个动作分量，同时保存相机画面和末端状态，观察该分量实际带来的变化。

| 实验 | 怎么做 | 看什么 |
| --- | --- | --- |
| 平移 | 从相同初始状态分别令 `dx = 0.25` 和 `dx = -0.25`，其余分量为 0 | 对照执行前后的末端 X 坐标，观察实际位移方向 |
| 旋转 | 从相同初始状态分别令 `rz = 0.25` 和 `rz = -0.25`，其余分量为 0 | 对照末端朝向和夹爪画面，观察相反方向的旋转 |
| 夹爪 | 前六个分量保持为 0，连续发送几步 `gripper = +1`，再发送几步 `gripper = -1` | 对照夹爪关节读数和画面，看两指先靠拢再分开 |

## 环境与运行入口

复用第 01 章的 LIBERO 和 MuJoCo 环境。实验只用手写动作，所需的就是红杯场景。环境准备和渲染检查见 [第 01 章实验](../01_environment/experiment.md)。
