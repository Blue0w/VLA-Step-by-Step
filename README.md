# VLA-Step-by-Step
面向具身智能爱好者、非 AI 专业人士也能看懂的 VLA 动手教程。从基本原理、模块代码到完整模型训练与仿真，一步步搭建自己的视觉语言动作模型。

A hands-on VLA tutorial for anyone curious about embodied AI—no AI background required. Explore the fundamentals, understand each module, and build, train, and simulate your own Vision-Language-Action model step by step.
